# Fylvix — Environment Variables Reference

Configure these keys in `.env` (or via the **Secrets panel in AI Studio**):

| Variable | Description | Example |
| :--- | :--- | :--- |
| `API_BASE_URL` | Base URL for the Fylvix REST API | `https://api.fylvix.global` |
| `METADATA_API_URL` | Upstream metadata synchronization service endpoint | `https://metadata.fylvix.global` |
| `METADATA_API_KEY` | API key for backend metadata provider synchronization | `FYLVIX_METADATA_PROVIDER_KEY_PLACEHOLDER` |
| `MEDIA_API_URL` | Authorized CDN / HLS / DASH playback token service | `https://media-cdn.fylvix.global` |
| `ANALYTICS_KEY` | Aggregate privacy-safe analytics write key | `FYLVIX_ANALYTICS_KEY_PLACEHOLDER` |
